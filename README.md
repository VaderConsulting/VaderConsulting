# VaderConsulting

Personal GitHub archive of development projects spanning ~2005 to present — a mix of tools, libraries, proof-of-concepts, and active research work in C# / .NET.

---

## About This Archive

Many of these repositories contain code written over a long period of time, some of it predating GitHub itself. A number of projects were originally built by adapting or studying code from community sources such as [CodeProject](https://www.codeproject.com), open-source libraries, or examples found online.

**I do not claim all code here as entirely my own original work.**

Where the original author or source is known, it is documented in the individual repository's `LICENSE` or `THIRD_PARTY_NOTICES.md` file. Where the original source cannot be traced with certainty, a provenance notice is included instead.

If you recognise code in any repository as your own work and it is not properly attributed, please [open an issue](https://github.com/VaderConsulting) in the relevant repository and I will add attribution or take the repository down promptly.
